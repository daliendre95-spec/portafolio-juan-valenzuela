# Juan Pablo Valenzuela — Portfolio

Sitio estático editorial: Fashion, Culture & Brand Communication.

## Publicar en GitHub Pages

1. Subí este repositorio a GitHub.
2. En el repo: **Settings → Pages**.
3. **Build and deployment → Source:** Deploy from a branch.
4. **Branch:** `main` / **Folder:** `/ (root)`.
5. Guardá; en unos minutos el sitio estará en `https://<usuario>.github.io/<repo>/`.

Abrí `index.html` en la raíz; no hace falta build.
